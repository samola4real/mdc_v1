# Phase 4 reports

Codex publishes each Phase 4 implementation, audit, or validation report as Markdown in this directory on its task branch. Use the matching numbered prompt in [`../prompts_phase4/`](../prompts_phase4/) and report the branch, commit SHA, and direct GitHub link. Reports are reviewed before merge. Record evidence, verdict, blockers, and any changes; never include credentials or secret values.

Historical reports under other directories remain where they were published.
